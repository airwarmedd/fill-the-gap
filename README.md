# Upskilling Tracker

A 12-week tracker for learning AI-native growth, developer marketing and DevRel skills, built with Claude.

**Live:** https://airwarmedd.github.io/upskilling-tracker/

## What it does

- Tracks 46 items across four areas: skills to understand, a week-by-week plan, certifications, courses and tests, and portfolio projects.
- Tick an item when it's done. Progress bars show where you stand overall and per area.
- Each item has two notes fields: **What I've understood** and **The gap I still feel**. The **My gaps** view collects every gap in one place.
- **This week** shows only what's due now, based on a start date of Monday 12 October 2026.

## Where your data goes

Nowhere. Ticks and notes are saved in your own browser's local storage. Use **Export my notes** to back up a JSON file, and **Import notes** to restore it or move it to another device.

## Tech

One self-contained `index.html`, no build step and no dependencies. Fonts load from Google Fonts. Hosted on GitHub Pages.
